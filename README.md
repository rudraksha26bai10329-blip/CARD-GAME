# CARD-GAME

# Object-Oriented Text-Based Card Game Simulator

A modular, extensible Python terminal simulation of a classic High-Card game. Built using Object-Oriented Programming (OOP) principles, this project provides a core architecture for building complex card games (e.g., Blackjack, Poker, War).

## Features
- **Full Standard Deck**: 52 unique playing cards with standard suits and numerical rank evaluations.
- **Automated Dealing & Scoring**: Round-by-round evaluation, handling multi-player ties and total win tracking.
- **Interactive CLI Loop**: Step through rounds or exit at any point via simple command-line prompts.
- **Unit Tested**: Fully covered with automated tests using `unittest`.
